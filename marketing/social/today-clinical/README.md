# Today Social Creative - Clinical Theme

Theme: `Payment Confidence Protocol`

This pack gives Bit Bridge Global one premium post you can publish today.

## Files

- `marketing/social/today-clinical/template.html`: visual design canvas (1080x1350)
- `marketing/social/today-clinical/style.css`: clinical visual system
- `marketing/social/today-clinical/render.mjs`: exports PNG from the HTML template
- `marketing/social/today-clinical/today-copy.md`: caption copy for LinkedIn, X, Instagram
- `marketing/social/today-clinical/output/today-clinical.png`: exported image

## Brand Compliance

- Uses logo from `assets/logos/bitbridge-logo-clear.png`
- Always pairs the logo mark with the full name `Bit Bridge Global`

## Export

```bash
node marketing/social/today-clinical/render.mjs
```
