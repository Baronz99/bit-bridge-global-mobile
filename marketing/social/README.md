# Bit Bridge Global Social Content Kit

This folder contains a 30-day social media system you can run from VS Code.

## Brand Rules

- Canonical name: `Bit Bridge Global`
- Logo file: `assets/logos/bitbridge-logo-clear.png`
- If a design uses the logo-only mark, add the brand text `Bit Bridge Global` next to or below it.
- Keep naming consistent across all channels: do not switch between `BitBridge` and `Bit Bridge Global` in the same post.

## Files

- `marketing/social/30-day-calendar.csv`: publishing plan for 30 days
- `marketing/social/30-day-posts.md`: ready-to-post copy for LinkedIn, X, and Instagram

## Suggested Weekly Rhythm

- Monday: product education
- Tuesday: feature proof/demo
- Wednesday: trust/security
- Thursday: user scenario
- Friday: product update/build-in-public
- Saturday: community engagement/poll
- Sunday: recap + CTA

## Fast Workflow in VS Code

1. Open `30-day-calendar.csv` and pick the day.
2. Copy matching draft from `30-day-posts.md`.
3. Add current links/screenshots and publish.
4. Track what performed best by adding notes in the CSV.

## Asset Checklist

- Add logo + `Bit Bridge Global` text lockup where needed.
- Use one clear CTA per post.
- Reuse app screenshots from `marketing/appstore/output/`.
- Keep short-form videos under 45 seconds and include subtitles.
