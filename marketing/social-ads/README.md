# BitBridge Global Social Ads

This pack creates a premium fintech ad system using local BitBridge assets:

- Logo source: `assets/logos/bitbridge-logo-clear.png`
- Brand-inspired color tokens pulled from existing BitBridge marketing assets:
  - `#050A18` deep navy
  - `#0B1630` midnight blue
  - `#D6B15E` signal gold
  - `#3D78FF` trust blue
  - `#14B8A6` secure teal

## Concept

- Tone: trust-forward, banking-grade, minimal and modern
- Layout: bold headline + focused subtext + clean phone UI mock
- Depth: layered radial gradients, restrained glow, soft panel elevation
- Usage: one visual system across 5 messages and 3 output sizes

## Export

```bash
node marketing/social-ads/render.mjs
```

## Output

Generated files are written to:

- `marketing/social-ads/output/`

15 PNG files are produced:

- 5 ad concepts x 3 sizes (`1080x1080`, `1080x1920`, `1200x628`)
